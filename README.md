# OVERDRIVE 89

เกมแข่งรถออนไลน์บนเว็บ แนวไซเบอร์พังก์ย้อนยุค (Phaser + GitHub Pages)

## โครงสร้างไฟล์ (วางไว้ใน repo ระดับบนสุดทั้งหมด)

| ไฟล์ | หน้าที่ | แก้เมื่อไหร่ |
|---|---|---|
| `index.html` | โครงหน้าเว็บ + เมนู + HUD | เพิ่มปุ่ม/หน้าจอใหม่ |
| `style.css` | หน้าตาทั้งหมด | เปลี่ยนสี/ขนาดปุ่ม |
| `config.js` | **ค่าตั้งต้นทั้งหมด** (ฟิสิกส์รถ, รางวัล, ราคา, คีย์ Supabase) | ปรับความรู้สึกขับ/สมดุลเกม |
| `track.js` | ข้อมูลสนาม | เพิ่มสนามใหม่ (เพิ่มใน `TRACKS`) |
| `car.js` | ฟิสิกส์รถ ดริฟต์ เทอร์โบ | แก้การควบคุมรถ |
| `race.js` | ฉากแข่ง (วาดสนาม กล้อง นับรอบ) | เพิ่มรถคู่แข่ง ไอเทมบนสนาม |
| `input.js` | ปุ่มสัมผัส + คีย์บอร์ด | ย้ายตำแหน่งปุ่ม |
| `ui.js` | HUD, แผนที่ย่อ, ป้ายโค้ง, เต็มจอ | เพิ่มข้อมูลบนจอ |
| `save.js` | เลเวล EXP เหรียญ อัปเกรด | เพิ่มอะไหล่/ไอเทมในอู่ |
| `auth.js` | เชื่อมอีเมล (Supabase) | ระบบออนไลน์ |
| `menu.js` | หน้าเมนู ทดลองเล่น / เชื่อมอีเมล | เพิ่มเมนูใหม่ |
| `session.js` | โหมดปัจจุบัน (ทดลอง / ออนไลน์) | ต่อห้องแข่งกับเพื่อน |
| `main.js` | จุดเริ่มต้น ผูกทุกส่วนเข้าด้วยกัน | ไม่ค่อยต้องแก้ |

## เปิดระบบเชื่อมอีเมลจริง (Supabase)
1. สมัคร supabase.com แล้วสร้างโปรเจกต์
2. Authentication > URL Configuration: ใส่ลิงก์เกมของคุณ (`https://ชื่อผู้ใช้.github.io/OVERDRIVE-89/`) ที่ Site URL และ Redirect URLs
3. Project Settings > API: คัดลอก **Project URL** และ **anon public key** ไปใส่ใน `config.js` (`supabaseUrl`, `supabaseKey`)
   - ใช้ anon key เท่านั้น ห้ามใส่ `service_role` ลงใน repo
4. กดปุ่ม "เชื่อมอีเมล" ในเกม ระบบจะส่งลิงก์เข้าอีเมล เปิดลิงก์แล้วกลับมาเล่น
